# Local Translator

This Windows application translates text locally with Ollama. Paste a technical document into the source field, choose the translation direction, and press Translate. The result appears gradually on the right. Japanese output uses a polite style.

## Setup

Start Ollama before opening the application. The default endpoint is http://127.0.0.1:11434. Download the translation model once before using it. Subsequent translations do not require an external translation service or an API key.

## Input

The source is limited to 2,048 characters, including spaces and line breaks. If the limit is exceeded, the application keeps the entire source and disables translation. Shorten the text to continue. Empty input cannot be translated. Language detection is not automatic: select English to Japanese or Japanese to English.

## Cancellation

Press Cancel to stop a request. The partial result remains visible and is marked as incomplete. You can edit the source and try again. Canceling a request does not stop the Ollama service or remove the installed model.

## Troubleshooting

If a connection fails, check that Ollama is running. Do not delete the configuration file at C:\Data\config.json. Save a backup before updating the application. Network failures must not erase text that the user entered. A request has a timeout of 3 minutes because the first model load can take longer than later requests.

## Copying results

Use Copy Result after generation ends. If another program temporarily locks the clipboard, wait a moment and retry. This application does not save translation history. Review technical terms, file paths, and numbers before using a translation in a published document.
